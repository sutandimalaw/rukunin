01 Ringkasan Eksekutif

Rukunin adalah aplikasi web untuk digitalisasi administrasi RT/RW di Indonesia. Mencakup manajemen kependudukan, keuangan, iuran warga, pengumuman, kegiatan komunitas, layanan warga, inventaris, dan portal self-service — semua dalam satu platform.

Posisi Saat Ini
Produk sudah ~85% feature-complete dengan 16 modul aktif. Siap pilot project.

Tujuan

AspekDetail
PortfolioBukti nyata kemampuan full-stack development production-grade
Side IncomePassive income dari langganan bulanan RT
FondasiCodebase & pengalaman untuk project IT selanjutnya

06 Timeline & Milestone

Fase 0 — April 2026 (Minggu 1-2)
Finalisasi Produk
Selesaikan Dashboard Admin dinamis dan Portal Warga enhancement. Testing manual seluruh flow admin + warga. Fix bugs.
  • Produk siap demo tanpa bug kritis
  • Semua 16 modul berfungsi end-to-end
Fase 1 — Mei 2026 (Minggu 3-6)
Deployment & Pilot RT 4
Beli domain & VPS. Deploy production. Setup akun admin RT 4. Input data awal warga. Training pengurus. Sosialisasi ke warga.
  • Sistem online & accessible 24/7
  • Pengurus RT bisa input/edit data warga
  • Minimal 20% warga register di portal
  • Iuran bulan pertama di-generate via sistem
Fase 2 — Juni-Juli 2026 (Minggu 7-14)
Stabilisasi & Feedback
Monitor penggunaan. Fix bugs berdasarkan feedback. Setup backup otomatis. Kumpulkan testimoni dari pengurus RT 4.
  • Uptime >99% selama 2 bulan
  • Minimal 50% warga aktif di portal
  • 1 testimoni tertulis dari pengurus RT 4
  • Zero data loss / security incident
Fase 3 — Agustus-Oktober 2026 (Minggu 15-26)
Ekspansi & Portfolio
Buat landing page marketing. Approach RT tetangga via referral. Update portfolio online (LinkedIn, CV). Cari project IT berikutnya.
  • Landing page live di rukunin.my.id
  • Rukunin di-showcase di LinkedIn/portfolio
  • 1-2 RT tambahan (nice to have)
  • Identifikasi project IT berikutnya
Fase 4 — November 2026+
Passive Mode
Maintenance rutin (~2-4 jam/minggu). Terima RT baru organic. Fokus ke project lain. Rukunin berjalan autopilot.
